
# Customer Churn & Retention Intelligence

A SQL-only e-commerce customer analytics project using the Olist Brazilian E-Commerce dataset.

## Business Problem
Identify customers unlikely to purchase again, estimate revenue at risk, and develop data-driven retention recommendations.

## Technology Stack
- PostgreSQL 16+
- SQL
- DBeaver Community
- Git & GitHub

## Project Modules
1. Database Design
2. Data Cleaning
3. Customer Cohort Analysis
4. RFM Segmentation
5. Churn Analysis
6. Customer Lifetime Value
7. Revenue at Risk
8. Query Performance Optimization

## Project Status
In Progress

## Dataset
Olist Brazilian E-Commerce Public Dataset (Kaggle).
